quantummelaninmedia.com — Studio Site + In-Browser Game Host

Live · quantummelaninmedia.com

Sole engineer · Design, front end, asset pipeline, deploy gate

One hand-written page, 74 KB, zero frameworks and zero third-party scripts, answering in about half a second. It hosts two complete WebGL games playable in the browser on the domain itself — a Three.js racer and a chess engine, no download and no signup — and opens the interior art of four graphic novels in a keyboard-navigable lightbox. It replaced a 540px column of emoji link cards where every card was an invitation to leave the site.

Audit

Nothing was shown, only named. Three product links pointed at the wrong books, one title was never listed, and GitHub Pages offers no staging — a push to main is production, immediately.

Evals

A pre-deploy harness screenshots desktop and phone, then fails the build on 404s, JS errors, broken images, horizontal overflow, and any video whose clock does not advance when you press play.

Deployment

The hero shipped a VP9 webm that returned 200, reported the right duration, and decoded clean under ffmpeg — and froze on its poster in every Chrome install. Every check agreed and all of them were wrong. Changed the format, not the encoder settings, and made the play check permanent.

HTML/CSS/JS Three.js / WebGL Playwright Node ffmpeg PyMuPDF GitHub Pages

Alignment 365 — Wellness Subscription Platform

Live · alignment365.onrender.com

Solo founder-engineer · Full stack, auth, payments, ops

Subscription wellness product with dual-path authentication (Google Sign-In + email/password), live Stripe billing on Quantus AI's merchant account, and a Playwright-based ops layer that scripts Render + Stripe admin actions so config changes never require a human clicking through dashboards under pressure.

Audit

Existing auth silently failed for Google users; email/password had no recovery path. Real users were locked out.

Evals

Playwright regression harness that replays the full checkout + login flow against live Stripe test + live keys before every deploy.

Deployment

Rotated OAuth client ID, shipped both auth paths to prod July 2026, monitored via scripted Render env editor pattern.

Python Render Stripe (live) Google OAuth Playwright Claude Code

MarketPulse — Trading Dashboard

Live on Render

Solo · Real-time data, hand-rolled SVG chart engine, precision UX

Trading dashboard built on Python stdlib (no framework) with a hand-rolled SVG Live chart: snap-to-candle precision, editable marks, drawable trend lines, and a signature gold neon glow on chart selection. Every pixel is intentional — no charting library, no React, no bloat. Traders can see and act on what they're seeing.

Audit

Off-the-shelf chart libraries drift 1–3px off the candle body — a killer for precision entry marking.

Evals

Snap-to-candle math verified against raw OHLC; visual regression on mark placement across zoom levels.

Deployment

Deployed to Render; iteration driven by real trader feedback on which drawing primitives actually get used.

Python stdlib SVG Vanilla JS Render Real-time data

Quantus AI + QMM Production Stack

Live · Gumroad + full media pipeline

Co-founder · Agent orchestration, creative pipeline, IP infrastructure

Quantum Melanin Media — an Afrofuturist media studio with a live commerce channel (novella on Gumroad), a locked 35-shot trailer for the Bloodline Saga IP, and a 66-shot pilot episode in production. Quantus AI is the agent layer running payments, ops, and the creative-generation pipeline: image, motion, and voice models orchestrated through a shared repo of skills, hooks, and configs (`qmm-stack`) that stays in parity across two production rigs.

Audit

Traditional media pipelines assume a studio team of 20. Ours is 2. The workflow that had to be rebuilt was everything — from shot planning to publishing.

Evals

Locked visual rules (heroes = warm gold; enemies = cold void-green; melanated skin non-negotiable) enforced as review gates on every generated asset.

Deployment

Gumroad live for novella; trailer locked and rendered; multi-rig source-of-truth repo keeps skills synced across workstations.
